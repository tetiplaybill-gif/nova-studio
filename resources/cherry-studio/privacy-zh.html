NOVA Studio 隐私政策

更新日期：2026 年 11 月 17 日
生效日期：2026 年 11 月 17 日

NOVA Studio（以下简称“本软件”）是 cdkai.cc 提供的桌面客户端，基于开源项目 Cherry Studio 修改而来。本政策说明本软件如何处理您的信息。本软件使用的 cdkai.cc 账户和 NOVA API 同时适用 cdkai.cc 隐私说明。

一、保存在您电脑上的数据

对话、助手、知识库、文件、设置和 API Key 保存在您电脑上的本软件数据目录中，不会上传到 cdkai.cc 或其他服务器。卸载本软件或删除数据目录即可清除这些数据。

二、发送到 cdkai.cc 的数据

  • 登录：您在 NOVA 账户卡片中输入的邮箱、密码和验证码只发送给 cdkai.cc 用于登录。登录后的会话凭据使用系统钥匙串加密保存在您的电脑上；系统钥匙串不可用时只保存在内存中，退出后需要重新登录。
  • API 请求：您与模型对话时，提示词、附件内容和模型回复会经 cdkai.cc 转发给相应的模型提供方处理。cdkai.cc 不保存请求和回复的正文，只记录用于计费和排查问题的元数据（时间、密钥、模型、用量、费用和状态码），保留不超过 180 天。
  • 余额与密钥：本软件会读取您的余额，并为这台电脑创建一个名为“NOVA Studio”的 API Key；退出登录时会删除该 Key。

三、本软件不收集的信息

本软件不发送使用统计、崩溃报告、设备标识或公告请求，也不连接 Cherry Studio 开发团队的任何服务。

四、您主动使用的第三方服务

如果您主动启用网页搜索、MCP 服务器、小程序、云存储备份（如 WebDAV、S3）或笔记同步（如 Notion、思源）等功能，相关数据会按您的配置发送给对应的第三方服务，并适用其隐私政策。这些功能默认不会自动连接。

五、模型提供方

模型提供方可能按其自身政策处理您通过 API 提交的内容。请勿在对话中提交不必要的敏感个人信息。

六、政策更新

本政策更新时，本软件会在启动时提示您阅读新版本。

七、联系我们

需要查询、更正或申请删除账户资料时，请通过 cdkai.cc 客服联系我们。
